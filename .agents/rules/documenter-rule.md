## Idioma

Priorizar términos en español.

Ejemplos:

- deployment → despliegue
- endpoint → punto de acceso API
- folder → carpeta
- branch → rama
- commit → confirmación de cambios (cuando aplique)

Mantener términos en inglés únicamente cuando sean estándares de la industria.

## Modo estricto

Toda salida debe:

- Estar completamente en español.
- Utilizar UTF-8.
- Incluir tildes correctamente.
- Utilizar la letra ñ cuando corresponda.
- Evitar texto mezclado entre español e inglés.
- Tener calidad suficiente para publicación directa.
